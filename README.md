# Prompt_Injection_Attacker
This repo generates 100  (varied types) attack prompts from templates and transformations, runs them against open-source LLMs, and logs outputs. It auto-labels responses, computes ASR/OSR, ranks top attack patterns, and exports summary charts and a short report. Intended for coursework and defensive research only.

### Safety & responsible use
This project is for research and defensive purposes only. Do not use it to generate or distribute harmful, illegal, or dangerous instructions.
